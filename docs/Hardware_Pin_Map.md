## 1 文档说明
### 1.1 文档目的
本文档为本项目硬件引脚分配的唯一设计依据，所有CubeMX外设配置、驱动代码开发、外部模块接线均需严格遵循本文档定义，禁止随意修改引脚与参数。

### 1.2 约束规则
1.  板载固定外设引脚不做重新分配，外接模块引脚统一规划后固化；
2.  所有引脚模式、有效电平、默认状态以本表为准，代码宏定义需与文档命名保持一致；
3.  后续引脚或参数变更，必须升级文档版本号并完整记录变更内容与影响范围；
4.  引脚分配已完成 datasheet 复用冲突校验，无外设功能重叠。

## 7 故障安全引脚状态定义
系统进入故障安全模式（核心自检失败、CAN总线离线、看门狗复位触发）时，所有输出引脚强制进入以下安全状态：
1.  **执行器类**：RELAY_LIGHT、RELAY_LOCK 强制输出低电平，继电器断开；
2.  **报警类**：BEEP 按故障等级执行对应报警节奏，RGB_RED 常亮；
3.  **状态指示类**：RGB_GREEN 强制熄灭；
4.  **输入类**：保留按键检测能力，支持故障清除操作。

## 8 引脚设计规范说明
### 8.1 复用冲突校验
本表所有引脚均已对照 STM32F103ZET6 数据手册完成外设复用功能校验，不存在引脚功能重叠、外设冲突问题。

### 8.2 代码命名规范
驱动层引脚宏定义统一遵循以下规则，与本文档外设名称一一对应：
```c
#define RELAY_LIGHT_PIN     GPIO_PIN_5
#define RELAY_LIGHT_PORT    GPIOC

#define RELAY_LOCK_PIN      GPIO_PIN_2
#define RELAY_LOCK_PORT     GPIOC

#define KEY1_PIN            GPIO_PIN_0
#define KEY1_PORT           GPIOA

#define KEY2_PIN            GPIO_PIN_13
#define KEY2_PORT           GPIOC

#define FB_LIGHT_PIN      GPIO_PIN_4
#define FB_LIGHT_PORT     GPIOC

#define FB_LOCK_PIN       GPIO_PIN_3
#define FB_LOCK_PORT      GPIOC

#define RGB_RED_PIN         GPIO_PIN_5
#define RGB_RED_PORT        GPIOB

#define RGB_GREEN_PIN       GPIO_PIN_0
#define RGB_GREEN_PORT      GPIOB

#define BEEP_PIN            GPIO_PIN_0
#define BEEP_PORT           GPIOC

```
